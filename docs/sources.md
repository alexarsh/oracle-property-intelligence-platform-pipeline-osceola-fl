# Sources, constraints and measured performance — Osceola County, FL

Every row published by the pipeline points back to one of the sources below via
`source_system` / `source_url`, and every file ingested is recorded in the
`source_loads` ledger (URL, SHA-256, bytes, rows, fetched-at, run id) which is
exported into each run's `coverage.json`.

## 1. Osceola County Property Appraiser — certified roll export

|               |                                                                                                                                                                                                                                                                                                                                                                                                                   |
| ------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Custodian     | Osceola County Property Appraiser (OCPA)                                                                                                                                                                                                                                                                                                                                                                          |
| URL           | https://www.property-appraiser.org/data/ (annual ZIPs, 2021–2025, hosted on Dropbox)                                                                                                                                                                                                                                                                                                                              |
| Access        | Bulk download, no auth, no geo-block. 2025 ZIP = 159.5 MB, ~2.9 GB extracted, pipe-delimited latin-1 CSVs                                                                                                                                                                                                                                                                                                         |
| Loaded tables | `vw_mdparcel` (210,853 parcels), `vw_mdsite` (221,594 situs rows), `vw_mdowner` (316,728), `vw_mdmail` (210,853 mailing addresses), `vw_mdBld` (171,115 buildings with actual/effective year), `vw_mdpermit` (322,266 permits incl. county + Kissimmee + St. Cloud, contractor name/phone, issue/final/CO dates), `vw_mdsales1930` (887,636 sales since 1930), `vw_mdDetail`, `vw_mdLegal_ln`, `lu_dor`, `lu_sub` |
| Measured      | Download ≈ 4 min (VPN) / <2 min (direct); DuckDB load of 2.97 M rows ≈ 32 s                                                                                                                                                                                                                                                                                                                                       |
| Quarantine    | 20 malformed rows rejected by the CSV reader are kept in DuckDB `reject_errors`; ~21k permit rows are short (fewer columns) and are loaded with NULL padding, not dropped                                                                                                                                                                                                                                         |
| Cadence       | Annual certification; the pipeline detects a new ZIP by SHA-256 and loads it as a new tax year                                                                                                                                                                                                                                                                                                                    |
| Gives us      | properties, ownership, mailing (out-of-area owners), roof-age proxies (year built, effective year), sales tenure, historical permit baseline with contractor identity                                                                                                                                                                                                                                             |
| Does not give | coordinates, license numbers, current permit status after certification                                                                                                                                                                                                                                                                                                                                           |

## 2. Osceola County GIS — Parcels feature layer

|             |                                                                                                                                                   |
| ----------- | ------------------------------------------------------------------------------------------------------------------------------------------------- |
| Custodian   | Osceola County GIS (ArcGIS Online, owner `OsceolaGIS`)                                                                                            |
| URL         | https://services6.arcgis.com/9zKHLCgIwu2HFA5O/arcgis/rest/services/Parcels/FeatureServer/0                                                        |
| Access      | ArcGIS REST, anonymous, `returnCentroid=true&outSR=4326`, 2,000 features per page, `supportsPagination`                                           |
| Volume      | 215,865 polygons → centroids; 210,141 of 210,853 appraiser parcels match (99.7%) — the remainder are new splits/combinations or non-mapped folios |
| Measured    | Full sweep 108 requests at concurrency 4 ≈ 3 min; resumable via checkpoint                                                                        |
| Incremental | `LastUpdate >= <previous run date>`                                                                                                               |
| Gives us    | latitude/longitude for radius search, GIS year built (cross-check), sale date/price cross-check                                                   |

## 3. Osceola County Permit Center — Accela Citizen Access

|                   |                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| ----------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Custodian         | Osceola County Building Office                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| URL               | https://permits.osceola.org/CitizenAccess/ (self-hosted Accela; `aca-prod.accela.com/OSCEOLA` is not used)                                                                                                                                                                                                                                                                                                                                                                                                                  |
| Access            | ASP.NET async postbacks (general search by record type `Building/Permit/Roofing/NA` + date range, 10 results per page, `CapDetail.aspx` per record). Reachable from EU and US egress                                                                                                                                                                                                                                                                                                                                        |
| Quirks            | (a) Server sends an incomplete TLS chain — the pipeline pins the Entrust intermediate certificate. (b) A search is capped at **100+ hits**; the harvester bisects date windows until none is capped. (c) Issued/finaled/closed dates are rendered client-side and are **not** in server HTML — status text ("Issued", "Final", "Application Submitted", "Pending") and the opened date are captured; open/closed is derived from status. (d) Temporary applications (`OSCTEMP…`) have no detail page and are kept list-only |
| Measured          | p50 ≈ 0.9 s, p95 ≈ 1.9 s per request at concurrency 2; ≈ 45 roofing permits per week; a January–September 2026 backfill is ≈ 1,500 permits and ≈ 1–1.5 h                                                                                                                                                                                                                                                                                                                                                                    |
| Gives us          | current roofing permits with **contractor business, qualifier, state license number (CCC…), phone**, job value, parcel, address                                                                                                                                                                                                                                                                                                                                                                                             |
| Coverage boundary | Unincorporated county only; City of Kissimmee and City of St. Cloud run separate portals (their history is present in the appraiser permit feed as agencies K / S)                                                                                                                                                                                                                                                                                                                                                          |

## 5. Overture Maps — places (business locations)

|              |                                                                                                                                                       |
| ------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------- |
| Custodian    | Overture Maps Foundation (public S3 bucket, no credentials)                                                                                           |
| URL          | `s3://overturemaps-us-west-2/release/<release>/theme=places/type=place/` — release pinned per run (2026-08-19.0)                                      |
| Access       | DuckDB `httpfs` + `spatial`: bounding-box row-group pruning on S3, then `ST_Within` against the Census cartographic county polygon (GEOID 12097)      |
| Volume       | 36,875 places in the county bounding box before clipping                                                                                              |
| Licence gate | rows sourced from OpenStreetMap are excluded (kit rule); source datasets are kept per row for attribution                                             |
| Gives us     | business records with category taxonomy, phone, website, coordinates; contractor businesses are linked to permit-derived contractor entities by phone |

## Sources evaluated and not used (and why)

| Source                             | Outcome                                                                                                                                                                                  |
| ---------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Florida DOR NAL/SDF tax roll files | The OCPA export already includes the NAL file; the DOR document library requires a login (HTTP 401)                                                                                      |
| Florida Sunbiz corporate registry  | Web search and data-download pages are geo-blocked (403) outside the US; the public bulk SFTP is a multi-GB statewide feed — deferred; business records are served from Overture instead |
| `aca-prod.accela.com/OSCEOLA`      | Times out; the county's own host is the live portal                                                                                                                                      |
| Census TIGERweb REST               | Rejected by a WAF; the cartographic boundary shapefile is used instead                                                                                                                   |

## Slow or constrained sources (summary for the run summary page)

1. **Accela portal** — the only source that needs many small requests; throughput is bounded by politeness (2 concurrent, ~1 s/request) and the 100-hit cap. Incremental windows keep each refresh to minutes.
2. **BBB** — browser-only, US-only, challenge pages; run weekly, not per run.
3. **Filebase upload from a VPN exit** — ≈135 KB/s per connection; the publisher uses multipart uploads with 4 parts in flight. From GitHub Actions the same upload takes seconds.
4. **Overture S3 scan** — 1–3 minutes per release; cached per release so it runs once until the release is bumped.
